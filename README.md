# Boss AI Helper Chrome Extension

Boss AI Helper 是一个 Chrome 浏览器扩展，旨在提升浏览体验和自动化操作。该扩展包含以下主要文件：

- `background.js`：扩展的后台脚本，处理事件和消息。
- `content.js`：注入到网页中的脚本，实现页面交互。
- `config.html` & `config.js`：扩展的配置界面及其逻辑。
- `manifest.json`：扩展的清单文件，定义权限和入口。
- `icon.png`：扩展图标。

## 安装与使用

1. 克隆本仓库到本地：
   ```sh
   git clone https://github.com/littlejacky/boss-ai-helper.git
   ```
2. 打开 Chrome，进入 `chrome://extensions/`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本项目文件夹。
5. 配置并使用扩展。
